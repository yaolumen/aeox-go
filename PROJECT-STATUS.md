# AEOX Store Lite — Project Status

Last updated: 2026-09-01

## Project Overview

Free ebook store for developers. Backend: Node.js + Express + JSON files. Frontend: Preact + htm. No database.

- **Live URL**: https://go.aeox.uk
- **Admin**: https://go.aeox.uk/admin.html?k=<auto-generated>
- **Version**: 2.4.2

## Technical Notes

### Server Management
- Start: `node server.js` (Hostinger 自带 Node 管理器会自动重启)
- Port: 3000 (configurable via PORT env)
- PID file: `.server.pid` (auto-managed)
- **Never** kill all node.exe — DevEco runs on node

### Data Safety
- All JSON writes use unique tmp filenames: `writeFile(name.tmp.{pid}.{ts}.{rnd})` → `rename(tmp, target)`
- `withLock` prevents concurrent writes to same file (all saveJson calls now wrapped)
- `flushDirty` batch-writes every 30 seconds with retry + cache rollback
- SIGTERM/SIGINT triggers `flushDirty` before exit

### Rate Limits
- Login: 5 req/60s per IP
- Checkout: 10 req/60s per IP
- Email recovery: IP 5 req/60s + email 3 req/5min (dual limit)
- AI chat: configured per provider

### CORS
- V1 API (`/api/v1/*`): CORS enabled, configurable via `CORS_ORIGINS` env (default: `*`)
- Admin API: same-origin only (no CORS)

### Frontend Dependencies
- Preact + hooks + htm served locally from `assets/lib/`
- No CDN dependency
- `createContext` is a preact core export, NOT hooks export
